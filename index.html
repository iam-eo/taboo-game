Taboo Guide & Help

Objective

Get your teammates to guess the Target Word at the top of the card before the timer runs out, without uttering the target word or any of the 5 forbidden Taboo words!

Player Roles & Rotation

  • Clue-Giver: Provides verbal clues to their team. When player names are entered (separated by commas), clue-givers automatically rotate each round!
  • Guessers: Active teammates shouting out answers.
  • Watchdogs: Opposing players monitoring for forbidden words or gestures.

Scoring & Controls

  • Start Turn: Hand the device to the active clue-giver and tap 'START TURN' to reveal cards and start timer.
  • Correct (+1): Team correctly guesses the word. Advance to next card.
  • Taboo Penalty (-1): Clue-giver says a forbidden word, derivative, or rhyming clue. Points are deducted!
  • Skip: Pass on a difficult card. Limited by the set skip quota.

Match Setup

Before starting, set your match preferences on the setup screen:

  • Set number of rounds (1 to 50 rounds).
  • Adjust turn timer (10s to 300s).
  • Set skip limit per turn (0 to 10 skips).
  • Add unlimited teams, set team names, and input player names separated by commas for automatic turn rotation!

Managing Decks & Cards

Tap the Database icon at the top to select from online deck presets (Default Deck, Deck 1–5) or import offline custom packs.

CSV Format: Format custom CSV files as:
TARGET, FORBIDDEN1, FORBIDDEN2, FORBIDDEN3, FORBIDDEN4, FORBIDDEN5

Step-by-Step Device Sync

  1. Host Phone: Keep role set to Host. Tap the Users icon to view your 4-digit Room Code.
  2. Player Phones: Open your GitHub Pages link on other phones. Tap the Users icon, switch role to Player, enter the 4-digit code, and tap JOIN.
  3. Real-Time Sync: Connected player displays instantly reflect active target cards, timer countdown, and current scores!

Offline & Local Wi-Fi

Because peer signaling uses WebRTC direct data channels, once connected, cards are stored in your device's browser memory (IndexedDB) and function seamlessly!

Q: Can I add my own language or word packs?

Yes! Prepare a CSV file containing your custom word deck and use the Import button in the Database menu. The app uses IndexedDB which can easily store up to 250,000+ custom entries!

Q: Room Code isn't connecting?

Make sure both devices have active network access (Wi-Fi or cellular) when initiating the initial WebRTC connection handshake.

Q: How do we prevent card repeats?

The app automatically shuffles the database indices using the Fisher-Yates algorithm. Cards will not repeat until every single card in your deck has been played.
