Taboo Guide & Help

Objective

Get your teammates to guess the Target Word before the timer runs out, without saying the target or any forbidden Taboo words!

Player Roles & Rotation

  • Clue-Giver: Provides verbal clues. Rotates each round automatically.
  • Guessers: Teammates shouting answers.
  • Watchdogs: Opposing players watching for penalties.

Scoring

  • Start Turn: Hand device to clue-giver, tap START TURN.
  • Correct (+1): Next card.
  • Taboo Penalty: Points deducted.
  • Skip: Pass card, quota-limited.

Match Setup

Configure rounds, timer, skips, teams, and players (comma-separated for auto rotation) before starting.

Decks & Cards

CSV Format:
TARGET, F1, F2, F3, F4, F5

Device Sync

  1. Host: Tap the users icon → view 4-digit code.
  2. Players: Switch to Player role → enter code → JOIN.
  3. Sync: Real-time card/timer/score updates.

Q: Custom language packs?

Yes — import any CSV/JSON via Database menu (up to 250k cards).

Q: Room code not connecting?

Both devices need network access for the initial WebRTC handshake.

Q: Prevent repeats?

Fisher-Yates shuffle; no card repeats until the deck is exhausted.
