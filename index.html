Taboo Guide & Help

Quick Start

  1. Host phone: set teams, tap START MATCH.
  2. Each player: open URL → Player role → enter code → Lookup → pick team → Join.
  3. Clue-giver sees card + SKIP.
  4. Opposing team sees card + TABOO/CORRECT.

Objective

Get teammates to guess the target word before time runs out, without saying forbidden words.

Roles per turn

  • Clue-Giver — sees card, controls START & SKIP.
  • Teammates — cannot see card, shout guesses.
  • Opposing Team — sees card, controls TABOO & CORRECT.

Joining

Type the host's 4-digit code and tap Lookup to fetch active teams. Then enter your name, pick a team, and tap Join.

Sync

Host taps the users icon to see the room code. Players use the lookup flow on their own phones.

AI Builder

Generate 50 fresh cards per category using a Gemini API key. Review and save to DB.

Q: What if my phone refreshes?

Re-enter code, tap Lookup, and join with the same name/team. It will replace the dead connection.
